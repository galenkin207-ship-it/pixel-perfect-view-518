# «Учёт работ» — визуальный прототип (моки, без бэкенда)

Мобильный PWA-инструмент для прорабов + десктопная админ-панель. Всё состояние — в памяти React, никакого бэкенда, БД и localStorage.

## Токен-план

**Палитра**
- Фон страницы: `#0B0B0C` (почти чёрный), панель/карточки: `#FFFFFF`, подложки: `#F5F6FA`
- Текст: тёмно-графитовый `#14161A`, вторичный серый `#8A8F98`
- Акцент: синий `#2F5FE0` (кнопки, активный пункт меню, аватары)
- Статусы: `done` зелёный `#3FAE59`, `in_progress` оранжевый `#E8A13A`, `on_review` бирюзовый `#0EA5B7` (намеренно отличается от акцентного синего), `rejected` красный `#E04F4F`
- Тёмная тема — та же система в тёмных тонах (все значения как семантические токены в `src/styles.css`, без хардкода цветов в компонентах)

**Типографика**: Inter, чистый sans. Заголовки крупные жирные, мелкие серые капслок-подписи над полями и группами меню. Числа — жирные.

**Радиусы/тени**: панель 24px, карточки 16px, поля-«пилюли» 12px, мягкая тень под плавающей панелью.

## Экраны

Роли: прораб (user), куратор (curator), администратор (admin) + переключатель «Смотреть как» в углу.

- **Объекты** — список карточек (прогресс по этапам у прораба), поиск, FAB «+»
- **Записи по объекту** — карточки с цветной полосой слева, объём, исполнитель, время, статус-бейдж
- **Новая запись** — «По сотруднику / По бригаде», виды работ (несколько позиций), сотрудник/бригада чипами, объём + единица, комментарий, фото, сумма только для admin
- **Выбор вида работ** — поиск по справочнику + «Указать свой вариант» → заявка
- **Отчёты** — дашборд (периоды, метрики, «По объектам»), подробные отчёты (статистика за период, комбинированный отчёт, месячный свод с «Скачать Excel»), на десктопе — таблица «Все записи»
- **Переписка** — заявки на новые виды работ, чат-треды, у admin — одобрение с ценой, история решений
- **Профиль** — карточка пользователя, тема, уведомления/Telegram, «Управление» (5 справочников, только admin), «Выйти»
- **Вход** — белая карточка на тёмном фоне

## Технические детали

- TanStack Start, маршруты в `src/routes`: `/` (объекты), `/objects/$id`, `/records/new`, `/reports`, `/reports/all`, `/messages`, `/profile`, `/profile/manage/*`, `/login`
- Общий layout в `__root.tsx`: сайдбар на десктопе / нижний таб-бар на мобильном, переключатель роли
- Моки и типы (`Object`, `Record`, `Request`, `User` с именами полей из ТЗ) — в `src/data/mock.ts`, состояние через React Context (`AppProvider`): роль, тема, записи, заявки, справочники
- shadcn-компоненты для полей/бейджей/диалогов, все цвета — токены в `src/styles.css`
- Русские моковые данные, никаких сетевых вызовов и хранилищ

Объём большой — предлагаю делать волнами: сначала дизайн-система + shell + Объекты/Записи/Новая запись, затем Отчёты и Переписка, затем Профиль/Управление и Вход.
